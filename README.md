# Bincom Interview Test – Python Trainee Intern

This repository contains my solution to the Bincom Python Trainee Developer Intern interview test.  
The project is built with **Flask** and connects to the provided `bincom_test` MySQL database.

---

## 🚀 Features Implemented
- **Question 1:** `/polling-unit`  
  Displays results for any polling unit by entering its unique ID.

- **Question 2:** `/lga-results`  
  Computes summed totals of all polling units under a selected Local Government Area (LGA).

- **Question 3:** `/new-polling-unit`  
  Allows adding a new polling unit and storing results for all parties.

---

## 🛠️ Requirements
- Python 3.14+  
- MySQL server with `bincom_test` database imported  
- Flask  
- PyMySQL
